<details>
<summary><b>🧰 &nbsp;How I build the admin panels</b></summary>
<br/>

- Every screen says *where on the public site* the content appears, in plain Chinese — no jargon, no i18n keys.
- One sticky save bar; anything that changes lights it up. Photo uploads are part of the same save, never a separate step.
- Alt text is enforced by the database schema, not by discipline.
- Row Level Security does the filtering; the app never re-implements "is this published?".
- Tested from a phone that has never signed in — because the owner's cookie hides exactly the bugs her customers would hit.
